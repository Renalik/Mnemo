# Mnemo 1.3

По просьбе пользователя убраны собственные ограничения Mnemo на размер одного файла, общий размер сообщения, количество вложений, объём извлечённого текста PDF и размер закодированного запроса Gemini.

Сняты проверки в выборе файлов, добавлении вложений, отправке сообщения и обработке PDF. Файлы читаются с опцией отображения в память, когда это допускает система. Ограничения провайдеров API, поддерживаемых форматов, контекста модели и возможностей устройства сохраняются: приложение не может их отменить.

Версия 1.3.0 (4). Код: `2845e68238af09212ff59f13f55ec98dbc0c4d76`. [Быстрая сборка](https://github.com/Renalik/Mnemo/actions/runs/42285189406).

Проверен синтаксис 38 Swift-файлов, plist и YAML. По просьбе пользователя длительные тесты и вариант с виджетами в этой сборке пропущены. Реальная отправка очень больших файлов с личными API-ключами не проверялась.

Основная сборка iPhone успешно скомпилирована. Проверены состав IPA, версия 1.3.0 и прежний идентификатор приложения. Готовый файл: `build/Mnemo-1.3.ipa`; SHA-256: `7dc94d70550b842699d51c54defc4261e3129dc091e2eb54736afc54d4aa92e3`.
