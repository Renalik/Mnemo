# Mnemo 1.2

- Встроенные профили Kimi (Moonshot International), Qwen (Alibaba Cloud Singapore), GLM (Z.ai), MiniMax International и StepFun Global. DeepSeek, Gemini, OpenAI, OpenRouter и другой совместимый API сохранены.
- Ключи и модели разделены по сервисам, используются прежние подтверждения действий помощника. Список моделей запрашивается у сервиса; если он не предоставляет каталог, ID можно указать вручную.
- Вместо прежних 12 МБ и 6 вложений: до 50 МБ на файл, до 100 МБ на сообщение, до 20 вложений. В UI и обработчике отправки используются одни константы. Лимит извлечённого из PDF текста увеличен с 1 до 8 МБ.
- Время ожидания запроса увеличено до 180 секунд, общего обмена — до 300 секунд.
- Ограничение 12 МБ было ограничением самого Mnemo для расхода памяти и размера запроса. Оно не являлось общим лимитом API.
- У провайдеров остаются свои ограничения: изображения поддерживаются не всеми моделями, объём текста ограничен контекстом. Для Gemini учитывается документированный предел 100 МБ закодированного запроса: base64 увеличивает размер, поэтому несколько крупных файлов может потребоваться отправить по отдельности. Приложение сообщает об этом до отправки.
- Ключи обычного API и подписок на чат / Coding Plan могут различаться. Qwen настроен на Singapore, StepFun — на Global. Другой региональный адрес можно подключить через «Другой сервис».

По просьбе пользователя сборка выполняется без длительных тестов симулятора. Проверены синтаксис 38 Swift-файлов и корректность plist/YAML. Окончательный результат сборки будет добавлен после завершения GitHub Actions. Реальные запросы с личными ключами к новым сервисам не выполнялись.
