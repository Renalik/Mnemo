# Mnemo 1.1

## Изменения

- На всех страницах с нижним меню добавлен запас прокрутки 96 pt. Последние блоки можно поднять выше меню. Высота меню явно зафиксирована; системный нижний отступ сохранён.
- В настройках колоды убрана общая овальная подложка iOS. Круглая стеклянная кнопка осталась.
- Колода удаляется через её настройки с отдельным подтверждением и числом карточек. Удаляются записи выбранной колоды, её карточки и история повторений. Данные других колод сохраняются. Медиафайлы на диске автоматически не удаляются; резервная копия включает только используемые вложения.
- В настройках и первом запуске можно выбрать Gemini, DeepSeek, OpenAI или OpenRouter. В настройках доступен другой сервис с HTTPS API формата OpenAI Chat Completions и поддержкой function calling.
- У каждого сервиса свой ключ в Keychain и свой выбор модели. Для произвольного сервиса ключ дополнительно привязан к конкретному адресу API. Ключи исключены из резервной копии.
- Список моделей загружается с сервера. Есть ручной ввод ID. Требуется модель с поддержкой tools/function calling; для фото нужна поддержка изображений.
- Чат, создание карточек, улучшение вопросов и проверка ответов используют выбранный сервис. Все изменения ИИ по-прежнему показываются перед применением. Удаление через ИИ не разрешено.
- Сохранена совместимость с библиотеками 1.0 и существующим ключом Gemini. Идентификатор приложения не меняется.

## Вложения

Gemini получает текст, изображения, PDF и аудио по прежнему протоколу. Для других сервисов передаются текст и изображения; из PDF локально извлекается текст. Если PDF состоит из сканов, приложение предлагает прикрепить фото страниц. Аудиофайл для этих сервисов отклоняется с предложением использовать диктовку. Возможности конкретной модели определяет её сервис.

## Как пользоваться

1. Обновить Mnemo поверх установленного приложения тем же Apple ID. Перед обновлением сохранить резервную копию в «Настройки → Резервная копия».
2. Открыть «Настройки → Сервис, ключ и модель», выбрать сервис, ввести его API-ключ.
3. Выбрать модель из списка или ввести её ID и нажать «Использовать эту модель».
4. Для удаления: «Колоды → нужная колода → круглая кнопка настроек справа сверху → Удалить колоду». На следующем шаге можно отменить удаление.
