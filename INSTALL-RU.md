# Установка Mnemo с Windows

Для первого подключения нужен iPhone, кабель, Windows и ваш Apple ID. Дальше SideStore позволяет обновлять подпись на iPhone через Wi-Fi. Бесплатная подпись Apple действует 7 дней.

1. Скачайте ZIP **Mnemo-free** из последней успешной [сборки GitHub](https://github.com/Renalik/Mnemo/actions). Распакуйте его: нужен файл `Mnemo-free.ipa`.
2. Установите SideStore по [официальной инструкции](https://docs.sidestore.io/docs/installation/prerequisites). Сейчас документация предлагает iloader для первой установки с Windows и LocalDevVPN на телефоне. Следуйте актуальным шагам для вашей версии iOS. Не передавайте Apple ID и пароль разработчику Mnemo и не добавляйте их в GitHub.
3. Включите режим разработчика и доверьтесь профилю, если iOS попросит. В SideStore выберите скачанный IPA и подпишите своим Apple ID.
4. До истечения 7 дней обновляйте подпись в SideStore. Во время установки и продления ему нужен LocalDevVPN и Wi-Fi. VPN для Gemini может потребоваться временно отключить на время работы SideStore: это разные задачи VPN.
5. Запустите Mnemo и выберите язык, тему, нагрузку и уведомления. Gemini можно подключить позже: Настройки → Сервис, ключ и модель → выбрать сервис → Сохранить ключ.

Запасной способ первой установки — [Sideloadly](https://sideloadly.io/) на Windows. Подпись через Sideloadly и продление через SideStore требуют согласованной установки; проще сразу установить Mnemo через SideStore. Не рассчитывайте, что разные программы автоматически разделят одну подпись и профиль.

Apple ограничивает бесплатный Personal Team тремя приложениями на устройстве и десятью App ID за 7 дней. Расширения тоже могут расходовать идентификаторы. В бесплатном варианте Mnemo нет расширения виджетов; основные карточки, расписание, локальные уведомления, помощник ИИ и Face ID работают без App Group.

Виджеты и Live Activity лежат в отдельном варианте проекта. Для их полноценной работы нужна подпись с разрешённым App Group. Платная программа Apple требуется не только для App Store/TestFlight: некоторые расширенные возможности тоже зависят от неё. Не покупайте аккаунт ради Mnemo до проверки сборки и возможностей вашей установки.

Перед переустановкой сохраните копию: Настройки → Резервная копия → Сохранить в Файлы. Удаление приложения на iPhone удаляет локальные карточки. Для второго телефона перенесите `.mnemo` через «Файлы», затем откройте Настройки → Импорт. API-ключ введите отдельно на каждом телефоне.

Источники: [ограничения Apple](https://developer.apple.com/help/account/basics/about-your-developer-account), [возможности подписи iOS](https://developer.apple.com/help/account/reference/supported-capabilities-ios), [SideStore](https://docs.sidestore.io/docs/installation/prerequisites).
